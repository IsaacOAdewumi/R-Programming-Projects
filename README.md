# Exploratory Data Analysis with R

**Author:** Isaac Olufemi Adewumi  
**Tools:** R, RStudio, tidyverse, ggplot2  
**Project type:** Data cleaning, exploratory analysis, and visualisation

## Project Overview

This project demonstrates a reproducible workflow for exploring a structured dataset with R. The analysis will inspect data quality, summarise important variables, explore relationships, and communicate patterns through visualisations.

The initial project is framed as a general exploratory data analysis (EDA) workflow so that the selected dataset can be documented accurately once it is uploaded. The final questions and analysis will be tailored to the variables available.

## Objectives

- Import and inspect a dataset in R.
- Identify missing values, duplicate records, inconsistent data types, and unusual observations.
- Produce descriptive summaries for relevant numeric and categorical variables.
- Explore distributions, group differences, trends, and relationships where appropriate.
- Create clear, reproducible charts.
- Translate the observed patterns into carefully qualified findings.

## Tools and Techniques

- R and RStudio
- `readr` or other suitable import functions
- `dplyr` and `tidyr` for data manipulation
- `ggplot2` for visualisation
- Descriptive statistics and grouped summaries
- Reproducible scripts and documented data-cleaning decisions

Packages will be finalised based on the chosen dataset and the analysis actually performed.

## Planned Workflow

1. Document the dataset source, structure, and intended use.
2. Import the data and inspect dimensions, variable types, and summary statistics.
3. Assess missingness, duplicates, and inconsistent values.
4. Clean or recode variables where justified and document the decisions.
5. Conduct exploratory summaries and visual analysis.
6. Check that charts and summaries accurately represent the data.
7. Write a short interpretation of the findings, limitations, and possible next steps.

## Results and Limitations

Results will be documented after the dataset is selected and the analysis is run. No numerical findings are claimed at this stage. Any conclusions will be descriptive unless the project design and data support stronger inference.

## How to Run

1. Install R and, optionally, RStudio.
2. Open the project scripts in the order indicated.
3. Place the permitted dataset in the documented data folder or update the file path.
4. Install any required packages that are not already available.
5. Run the scripts and review the generated tables and figures.
